# survey-tally

엑셀에서 복사한 설문 응답을 붙여넣으면 문항별 결과 표를 보여 주는 한 파일짜리 웹 페이지(`index.html`)입니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다(CSP로 외부 연결도 막음).

## 쓰는 법

1. `index.html`을 브라우저로 엽니다(GitHub Pages에 올려도 됩니다. `.nojekyll` 포함).
2. 엑셀에서 머리글 줄까지 범위를 복사해 입력 칸에 붙여넣습니다.
3. 문항 / 유효 응답 / 평균 / 빈 응답 / 제외 표가 바로 나옵니다.

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖은 제외.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 무시합니다.
- 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지. 유효가 0이면 `-`.

자세한 내용은 [PLAN.md](PLAN.md)를 보세요.

## 시험

```bash
npm test
```

외부 패키지가 필요 없습니다. 계산 로직은 `index.html`의 `<script id="tally-core">` 블록에 있고,
시험은 그 블록만 꺼내 Node에서 실행합니다. `playwright`가 설치돼 있으면 브라우저 시험도 함께 돌고,
없으면 그 시험만 건너뜁니다.
